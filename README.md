# Kalorienzähler

Schlichter Kalorienzähler für Android 11+ (optimiert für Oppo Reno 2 Z).
Scannen, suchen, schnell eintragen – ohne Konto, ohne Cloud, ohne Schnickschnack.

- Plan und Status: [BLOCKS.md](BLOCKS.md)
- Änderungen: [CHANGELOG.md](CHANGELOG.md)
- Regeln für die Entwicklung: [CLAUDE.md](CLAUDE.md)

## Installieren
Die fertige App liegt unter **Releases** als `.apk`. Auf dem Handy herunterladen und öffnen
(einmalig „Installation aus unbekannten Quellen“ erlauben). Updates installieren sich über die alte Version, Daten bleiben erhalten.
